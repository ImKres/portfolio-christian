# Christian Libuna, portfolio

Personal portfolio of Christian Libuna, Azure Infrastructure Specialist based in Metro Manila.

Open `index.html` in a browser. The styles, data and code are all in that one file. It also needs the `assets` folder, which holds the profile photo, the favicon and the certification badges.

## Sections
- **Overview**: intro, an animated globe, highlights and featured projects
- **Architecture**: interactive diagrams built with official Azure icons
- **Projects**: case studies that open as dropdowns
- **Experience**: roles at Philtech, Fujitsu and LEAP, plus education
- **Skills**: grouped skills, each linked to the projects and roles that used it
- **Certifications**: Microsoft and AWS badges
- **Contact**: email and LinkedIn

Also includes Ctrl+K search, light and dark themes, and a phone layout.

## Editing
All content is in the `PROJECTS`, `JOBS`, `SKILL_GROUPS`, `CERTS` and `TRAINING` lists near the top of the `<script>` in `index.html`.
